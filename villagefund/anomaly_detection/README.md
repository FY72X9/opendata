## 1. Associated Publication & Research Summary

- **Title**: *Unsupervised Dual-Path Consensus Machine Learning and Operational Policy Framework for Village Fund Expenditure Anomaly Detection*
- **Conference**: The 2nd International Conference on Digital Economy and Emerging Societies (ICDEES 2026)
- **Program & Schedule**: [ICDEES 2026 Program](https://dcs.binus.ac.id/icdees/post/icdees-2026-program-and-schedule/)
- **Funding Support**: Penelitian Pemula Binus, Contract No. `137/VRRTT/V1/2026` (Dated: June 2, 2026).

### Research Overview
This study addresses monitoring challenges across 75,259 Indonesian villages allocating ~Rp 71 trillion annually. Utilizing 96,778 transaction records across 1,363 villages in Jambi Province (FY 2023–2025), an unsupervised **Dual-Path Consensus Protocol** ($\text{LOF} \lor (\text{IF} \land \text{RDA})$) was developed to overcome subspace mutual cancellation between density and isolation methods. The artifact identifies 7,153 expenditure anomalies (7.39%) with Rp 642.85 billion in financial realization risk, reducing the district inspectorate (APIP) audit search space by 92.6%. In ex-ante synthetic fraud benchmarking ($N=10,000$; 5.0% fraud), the consensus achieved $F_1 = 0.846$ and $\text{AUC-ROC} = 0.912$ (vs. majority voting $F_1 = 0.568$).

## 2. Data Availability Statement

> **Data Availability Statement**:  
> Data supporting this study are openly available in this repository under folder [`villagefund/anomaly_detection/`](file:///d:/Codes/research_banks/opendata/villagefund/anomaly_detection). The datasets contain expert validation subsets and anomaly indicators generated by the three unsupervised learning architectures (Isolation Forest, Local Outlier Factor, and Reconstruction Dense Autoencoder). In accordance with UU RI No. 14/2008 (Keterbukaan Informasi Publik) and UU RI No. 11/2019 (Sisnas Iptek), no personally identifiable information (PII) is included; all records represent public municipal and administrative expenditure aggregations.

## 4. Data Dictionary (Schema)

All three CSV files share a standardized 19-column schema:

| Column Name | Data Type | Description |
|---|---|---|
| `Kode_Desa` | Integer | Kemendagri / BPS 10-digit unique village administrative code |
| `Tahun` | Integer | Fiscal budget year (2023, 2024, or 2025) |
| `Nama_Desa` | String | Village administrative name |
| `Uraian_Output` | String | Description of the sub-field development activity/output |
| `Cara_Pengadaan` | String | Procurement mechanism (e.g., `Swakelola`, `Pihak Ketiga`) |
| `if_score` | Float | Isolation Forest anomaly score (lower/negative indicates higher anomaly) |
| `if_flag` | Binary (0/1) | Isolation Forest binary classification flag (1 = anomalous) |
| `lof_score` | Float | Local Outlier Factor density score (> 1 indicates outlier density) |
| `lof_flag` | Binary (0/1) | Local Outlier Factor binary classification flag (1 = anomalous) |
| `rda_score` | Float | Mean Squared Error (MSE) neural reconstruction loss from RDA |
| `rda_flag` | Binary (0/1) | RDA binary classification flag (1 = anomalous) |
| `consensus_flag` | Binary (0/1) | Multi-model consensus flag indicating multi-detector agreement |
| `typology_primary` | String | Primary mapped corruption typology (e.g., `T1_Markup`, `T2_Ghost`, `Unclassified`) |
| `typologies_str` | String | Aggregate typology classifications mapped from domain heuristics |
| `top_error_feature` | String | Feature contributing the largest portion of reconstruction loss |
| `persistence_score` | Float | Normalized multi-year recurrence score ($0.0 - 1.0$) |
| `priority_tier` | String | APIP supervisory audit tier (`Tier 1 — High Priority`, `Tier 2 — Moderate`, etc.) |
| `expert_verdict` | String | Ground-truth review slot for legal and auditor validation |
| `modus_operandi_notes`| String | Expert qualitative annotation notes for investigative referral |
